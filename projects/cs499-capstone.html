Project Overview

A professional full-stack web application demonstrating software engineering best practices. The public portal showcases a responsive, performance-optimized browsing and search experience — including a custom-built search index, cached recommendations, and optimized database queries. This project demonstrates the application of design patterns, algorithmic problem-solving, and database performance tuning across a full-stack architecture. An authenticated Admin Portal for managing travel packages is a separate deployment, launching shortly.

Key Features

  • Trip Search: Custom Trie-based prefix search across trip names, resorts, and codes (O(m) lookup)
  • Smart Recommendations: LRU-cached, content-based recommendation engine (O(1) cached lookups)
  • Optimized Rankings: MinHeap-based top-K trip selection (O(n log k))
  • Database Performance: Indexed queries with .lean() optimization for read-heavy operations
  • Responsive Design: Works on desktop and mobile devices

Technical Stack

Backend

  • Node.js & Express.js
  • MongoDB & Mongoose
  • Passport.js
  • JWT Authentication

Software Engineering Improvements

  • 40% Code Reduction: Service layer eliminated duplicate error handling
  • 100% Type Safety: TypeScript interfaces prevent runtime errors
  • Centralized Error Handling: All errors managed from one location
  • Design Patterns: Service Layer, Middleware, Observable, Dependency Injection
  • Authentication/Authorization JWT-based security with route protection
